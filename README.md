# Laptop Dataset Data Cleansing Tool

A Python desktop app that cleans a messy laptop price dataset. Load a CSV, tick the cleaning steps you want, preview the result and export a clean file that is ready for analysis or machine learning.

Built with **Python, pandas and Tkinter** by **Mahnoor Zeeshan** (BSIT) as a data cleansing activity.

---

## Folder structure

```
Laptop-Data-Cleansing/
├── gui_app.py                          # Tkinter window (the app you run)
├── core_logic.py                       # Cleaning logic: clean_data() + default dataset path
├── data_cleansing.py                   # Data cleansing script
├── laptopData.csv                      # Raw dataset (input)

├── Laptop_Data_Cleansing_Report.docx   # Full written report

```

| File | What it is |
|---|---|
| `gui_app.py` | The interface. It has three tabs (Cleansing Control, Raw Preview, Cleaned Result), loads the CSV, collects the ticked options and shows the result. It contains no cleaning rules. |
| `core_logic.py` | The brain of the project. `clean_data(df, options)` does the cleaning, and `destination_path` is the default dataset the app loads on start. |
| `data_cleansing.py` | Data cleansing script. |
| `laptopData.csv` | The raw input: 1,303 rows x 12 columns. |
| `laptop_cleaned_final.csv` | The cleaned output: 1,242 rows x 19 columns. |
| `Laptop_Data_Cleansing_Report.docx` | The full report with code screenshots and before/after pictures. |
| `__pycache__/` | Python's cache folder. You do not need to upload it. |

## What the cleaning does

The raw file has empty rows, hidden `?` placeholders, duplicate laptops and numbers stuck inside text like `8GB` or `1.37kg`. Each checkbox in the app fixes one of these problems.

| Checkbox in the app | What it does |
|---|---|
| Remove Empty Rows & Index | Deletes completely empty rows and the useless `Unnamed: 0` index column |
| Clean `Ram` Column | `8GB` becomes `8` |
| Clean `Weight` & `Inches` | Removes `kg` and replaces the `?` placeholder with the column median |
| Parse `ScreenResolution` | Splits it into `Touchscreen`, `Ips`, `X_res`, `Y_res` and `ppi` |
| Parse `Cpu` | Splits it into `Cpu Brand` and `Cpu_Speed_GHz` |
| Parse `Memory` | Splits it into `HDD`, `SSD`, `Hybrid` and `Flash_Storage` (in GB) |
| Categorize `Gpu` & `OpSys` | Keeps the GPU brand (Intel / AMD / Nvidia) and groups the OS (Windows / Mac / Others) |
| Remove Duplicates | Deletes repeated laptop records |

|---|---|---|

## Getting started

### Requirements

- Python 3.8 or newer
- pandas
- Tkinter (included with Python on Windows and macOS)

On Linux, if Tkinter is missing:

```bash
sudo apt install python3-tk
```

### Install

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
pip install pandas
```

### Run

```bash
python gui_app.py
```

1. Click **Browse CSV...** (or **Load Project File**) and choose `laptopData.csv`.
2. Keep all the checkboxes ticked, or pick only the steps you want.
3. Click **Run Cleansing**.
4. Open the **Cleaned Result** tab and click **Export Cleaned CSV...**.

Keep `gui_app.py` and `core_logic.py` in the same folder, because the app imports `core_logic`.

---

## Things to know

- The two `?` values (one in `Weight`, one in `Inches`) are filled with the column median (2.04 kg and 15.6 inches). They are estimates, not real measurements.
- Operating systems and CPUs are grouped to keep the data simple, so a little detail is lost.
- Some extreme values (for example a 35.6 inch screen) are still in the data and should be checked before modelling.
- The preview tables show only 50 rows to stay fast. The exported file has every row.
